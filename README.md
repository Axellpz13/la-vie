# La vie

Une expérience web narrative qui suit plusieurs étapes de la vie. La page combine textes, images et animations déclenchées au défilement.

## Aperçu

Le visiteur parcourt une page continue, de la naissance à la vieillesse. Chaque section possède son ambiance visuelle et son contenu. Ce projet est un exercice de conception d’interface et de mise en scène du contenu.

## Technologies

- HTML pour la structure des sections
- CSS pour la mise en page, les ambiances et les adaptations visuelles
- JavaScript pour les effets de révélation au défilement

## Lancer le projet

1. Cloner ou télécharger le dépôt.
2. Ouvrir `index.html` dans un navigateur.

Aucune installation ni compilation n’est nécessaire.

## État

Projet d’apprentissage personnel. Les textes expriment un choix narratif ; le site ne prétend pas être une source d’information sur la psychologie ou la santé.
